# SE-Group-10-Clovet

Clovet adalah platform *marketplace fashion* web khusus kategori premium yang mengutamakan keamanan transaksi dan keaslian produk. Proyek ini mengintegrasikan sistem *Escrow*, pelacakan logistik *real-time*, dan teknologi *Natural Language Processing* (NLP) untuk klasifikasi cerdas.

## ✨ Fitur Utama
* **Sistem Transaksi Terproteksi (Escrow):** Penahanan dana untuk menjamin keamanan pembeli dan penjual.
* **Autentikasi Produk (Expert Verifier):** Alur verifikasi fisik dan digital untuk meminimalkan peredaran barang tiruan.
* **Smart-Listing Management:** Pengklasifikasian kategori produk secara otomatis menggunakan model NLP.
